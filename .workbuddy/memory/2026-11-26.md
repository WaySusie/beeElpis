## 前端工程化问题排查（beeElpis / feature/fontend-build）

逐个定位并修复了 5 个问题，全部经过实际编译/校验验证：

1. **webpack 配置校验报错**（满屏 WebpackOptions schema dump）→ `webpack.dev.js` 里 `devtools` 拼错，应为 `devtool`（用户自行改掉）。`additionalProperties: false` 导致满屏 schema 是 ValidationError 挂载的附件，真错误在上面。
2. **`el-input` 不生效** → `app/pages/boot.js` 里 `app.mount()` 写在 `app.use(ElementUI)` 之前，mount 后注册的全局组件对已渲染树无效。已调整顺序。
3. **`axios is not defined`** → 配置本身正确（`ProvidePlugin` 里 `axios: 'axios'` 写法没问题，实测能注入 `/* provided dependency */ var axios = require('axios')`）。真因是改了 webpack 配置没重启 compiler（webpack-dev-middleware 启动时创建 compiler，后续只热更源码）。
4. **HMR disabled 报错** → entry 加了 `webpack-hot-middleware/client` 但 `plugins` 为空。已加 `webpack.HotModuleReplacementPlugin()`；顺带修 client query 的 `?reload` → `&reload=true`（原写法把 reload 吞进 timeout 值里，且 reload 是布尔不是数字）。实测 runtime chunk 出现 `webpackHotUpdate`。
5. **commit-msg 校验失败** → 全局 `~/.cz-config.js`（`@csx/cz-customizable`）的 type.value 带 emoji（`🎸 feat`），撞上 `validate-commit-msg` 的 `/^\w+/` 正则。已把 13 个 value 的 emoji 去掉、保留在 name 里（菜单照常显示）。另给 `package.json` 加 `config.validate-commit-msg.types` 白名单，纳入 `config` 等类型。13 个类型复测全 PASS。
